# RoadSense Mobile — Bhavya B4

This folder contains the B4 mobile feature from the RoadSense task sheet.

Implemented:
- Native RoadSense warning icons with lucide-react-native.
- Voice alert using expo-speech.
- Reusable hazard alert card with an accessible Play alert action.

Voice message:
"Hazard reported nearby. Please drive carefully."

Run:
1. npm install
2. npx expo start
3. Open on an Android device with Expo Go.

This mobile work is isolated in its own folder and branch. The existing web application files are not changed by this B4 implementation.
